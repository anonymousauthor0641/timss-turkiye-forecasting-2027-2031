# Data notes

This folder contains the Türkiye-only analytical series used in the forecasting study.

- Analytical period: 1999–2023.
- The 1995 cycle is not used.
- The 2003 science and mathematics achievement scores were linearly interpolated between the 1999 and 2007 cycles:
  - Science: 443.5
  - Mathematics: 426.5
- Contextual variables for 2003 were also interpolated.
- 1999 categorical contextual variables were converted to weighted means and approximately harmonized to the later scale structure.
- 2007 contextual variables were retrospectively harmonized for longitudinal comparability.
- These harmonization steps are intended to improve comparability and do not constitute formal psychometric linking.
